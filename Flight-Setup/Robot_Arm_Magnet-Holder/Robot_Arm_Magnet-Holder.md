# Robotic Arm Magnet holder

[![Open GitHub folder]({{site.baseurl}}/assets/img/GitHub-Mark-32px.png) → to GitHub project folder](https://github.com/reiserlab/Fly-Lab-Gear/tree/main/Flight-Setup/Robot_Arm_Magnet-Holder){:.ifr}
An early-stage end-effector for attaching an electromagnet to a robotic arm. The intended use is automated positioning of a tethered fly in a flight arena: the robot arm moves the fly to a precise location, and the electromagnet can actively release it by reversing the field, unlike a static permanent magnet which requires mechanical separation.

![Magnet holder]({{site.baseurl}}/assets/img/Flight-Setup/Robot_Arm_Magnet-Holder/Robot_Arm_Magnet-Holder.png){: .ifr .pop}
`Robot_Arm_Magnet-Holder.FCStd`: A first geometry sketch for the mount. The design was not developed further and has not been tested. It is shared as a starting point in case the concept is useful for others working on automated fly placement in flight setups.
