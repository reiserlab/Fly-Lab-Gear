# Rotary Pump Adapters

[![Open GitHub folder]({{site.baseurl}}/assets/img/GitHub-Mark-32px.png) → to GitHub project folder](https://github.com/reiserlab/Fly-Lab-Gear/tree/main/Miscellaneous/Airflow){:.ifr}
The [sphere holder]({{site.baseurl}}/walking/sphere-holder) requires a continuous stream of pressurized air to float the treadmill sphere. Rotary pumps, commonly used to inflate air mattresses, are an inexpensive source for this. Their air outlets come in slightly different diameters depending on the manufacturer and batch. These adapters bridge the gap between the pump outlet and a standardized tubing size.

Three outlet diameters are covered:

| File | Outer diameter |
|------|----------------|
| `Rotary-pump-adapter_28.3mm.FCStd` | 28.3 mm |
| `Rotary-pump-adapter_31.0mm.FCStd` | 31.0 mm |
| `Rotary-pump-adapter_32.4mm.FCStd` | 32.4 mm |

Print-ready STL files for all three sizes are in the `production/` folder. The FreeCAD source files can be used to generate an adapter for a pump diameter not listed here.
